# Security

Report suspected vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/fridaysundaymood/indonesian-english-linter/security/advisories/new), rather than publishing exploit details in an issue. Do not attach credentials or private application data. No response SLA has been established.

Linting a Gradle project runs that project's Gradle wrapper and build scripts. Only lint projects whose code and build scripts you trust.
